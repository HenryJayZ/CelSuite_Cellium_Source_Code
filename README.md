# Cellium for Android

**A Made Easy LLM Bridge** — ported natively to **Android (Kotlin + Jetpack Compose)** with Liquid Glass neon-violet aesthetics, Cloud Firestore sync, Google Sign-In, Firebase AI Logic (Gemini), and the full 3,800-expression Cerebellium dot-matrix companion engine.

## Features
- **Cloud-Synced Chat Studio:** Real-time streaming with Gemini (`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-4-argon`), multimodal vision attachments via the zero-permission Android Photo Picker, `/imagine` artwork generation (`gemini-nano-banana-2.1`), collapsible `<think>` reasoning traces, Markdown & copyable code cards, TTS read-aloud, and synced conversation management (pin, rename, search, delete).
- **Interactive Welcome Companion Orb:** Glossy neon-violet orb with animated eyebrows, mood cross-fading, squishy tap bounce, and spam-tap rage mode.
- **Avatar Studio (3,800 Expressions):** All 5 Cerebellium styles (`Female`, `Male`, `Chibi`, `Detailed Female`, `Detailed Male`) × 76 base expressions × Base + 9 procedural modifiers, packed into a compact binary asset with real dot-matrix particle spring physics, eyelid fade-mask blink, touch repulsion, and headpat Animalese purrs.
- **CelAS Live Voice Mode:** Immersive full-screen voice call with on-device speech recognition, streaming Gemini voice replies, Android TTS speech sync driving mouth openness, live captions, and tap-to-barge-in.
- **Analytics & Dev Console:** Live workspace telemetry computed from Cloud Firestore plus an in-app developer log stream.
- **Settings, Custom Personas & Persistent Memories:** 8 built-in Cellium personas plus cloud-synced custom personas, toggleable persistent memories injected into prompts, audio/FPS/wallpaper preferences, and Google Sign-In account management.
